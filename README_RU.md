## О проекте

**Ланиакея** — одностраничное приложение на **Next.js 16 + React 19 + TypeScript +
Three.js**, визуализирующее сверхскопление галактик Ланиакея в 3D.

Модель построена по мотивам каталога собственных движений галактик **Cosmicflows**
(Tully et al., 2014) и показывает четыре региона сверхскопления, Великий аттрактор,
положение Млечного Пути и потоки галактик, стекающих к гравитационному центру.

Сцена работает целиком в браузере: датасет отдаётся статически, внешние сервисы не
требуются. Эмбиент синтезируется процедурно через Web Audio API, без аудиофайлов.
Речь озвучки идёт через Yandex SpeechKit, а если ключи не заданы — через встроенный
в браузер Web Speech API.

> Интерфейс приложения — на русском языке.

## Возможности

### Экскурсия

- **7 точек обзора**: Обзор Ланиакеи → Млечный Путь → Великий аттрактор →
  Гидра-Центавр → Павлин-Индеец → Южное сверхскопление → Местное сверхскопление.
- Плавный перелёт камеры между точками — 1.8 с, cubic ease-in-out.
- **Закадровый голос на русском** с текстом для каждой точки тура.
- **Субтитры**, синхронизированные с речью: текущее предложение подсвечивается,
  остальные приглушены.
- **Космический эмбиент** — процедурный дрон на Web Audio API: бас 55 Гц (A1),
  квинта 82.4 Гц (E2), медленный свип фильтра и шум «космической пыли».

### Сцена

- **~18 000 галактик** в сверхгалактических координатах — детерминированный датасет
  (ГПСЧ Mulberry32, сид `42`), отдаётся статически из `/api/galaxies`.
- **20 именованных объектов** с публикационными координатами: Млечный Путь, M31, M33,
  Cen A, группа M81, Sculptor, Maffei, M87, M49, M86, скопления Нормы, Центавра, Гидры,
  Antlia, Павлина, Индейца, Fornax, Эридана, Dorado.
- **4 региона**: Местное сверхскопление, Гидра-Центавр, Павлин-Индеец, Южное сверхскопление.
- **Великий аттрактор** — пульсирующее ядро с кольцами, похожими на аккреционный диск.
- **Анимированные потоки** галактик к Великому аттрактору.
- **Фон из 4 000 звёзд** на двух сферических оболочках.
- Светящиеся точки рисуются собственным GLSL-шейдером (мягкие круглые спрайты вместо
  квадратных пикселей), спиральные галактики вращаются дифференцированно — внутренние
  области быстрее внешних, как в реальности.
- **Постобработка**: Bloom, Vignette, SMAA.

### Инструменты

- **Мини-карта** (проекция XZ) с положением камеры; клик по ориентиру перелетает к нему.
- **Масштабная линейка** в мегапарсеках, пересчитывается под текущий зум.
- **Панель слоёв** — 4 региона, соседнее сверхскопление Персей-Рыбы, потоки, граница
  Ланиакеи, подписи, режим реальных галактик, свечение и параллакс.
- **Легенда** с цветами типов галактик.
- **Диалог «О Ланиакее»** — факты о диаметре, массе и каталоге.
- **Таймлайн открытий** — 15 событий от Хаббла (1924) до Tully (2014).
- **Сравнение сверхскоплений** — Ланиакея, Персей-Рыбы, Шепли, Хорологий-Сетка,
  Центавр (Pavo-Indus-Telescopium).
- **Скриншот в PNG**, **ссылка на текущий вид**, **экспорт тура в JSON**.
- **Обучающая заставка** при первом посещении (отметка хранится в `localStorage`).
- **Параллакс** — лёгкий дрейф камеры за курсором после 1.5 с бездействия.

## Установка и запуск

Нужен [Bun](https://bun.sh).

```bash
git clone https://github.com/QuadDarv1ne/laniakea.git
cd laniakea

bun install
bun dev
# → http://localhost:3000
```

**База данных не нужна** — приложение не обращается к внешним хранилищам.

## Скрипты

| Команда | Действие |
|---|---|
| `bun dev` | Dev-сервер на порту 3000, лог дублируется в `dev.log` |
| `bun build` | Продакшн-сборка + копирование `.next/static` и `public` в standalone |
| `bun start` | Запуск standalone-сервера, лог в `server.log` |
| `bun lint` | ESLint по всему проекту |

## Переменные окружения

Все необязательны. Без ключей приложение полностью рабочее — озвучка идёт через
Web Speech API браузера.

| Переменная | Назначение |
|---|---|
| `YANDEX_API_KEY` (или `YC_API_KEY`) | Ключ Yandex SpeechKit для серверного синтеза речи |
| `YC_FOLDER_ID` | ID каталога Yandex Cloud для того же запроса |

Используются только в `src/app/api/tts/route.ts`. Серверный синтез использует голос
`ermilov` — ближайший доступный аналог мужского русского голоса «Дмитрий».

## Горячие клавиши

Поддерживаются и латинская, и кириллическая раскладка.

| Клавиши | Действие |
|---|---|
| `←` / `→` | Предыдущая / следующая точка тура |
| `Space` | Включить или выключить закадровый голос |
| `R` / `К` | Сбросить вид |
| `S` / `Ы` | Скриншот в PNG |
| `L` / `Д` | Подписи объектов в 3D |
| `B` / `И` | Эффект свечения (Bloom) |
| `P` / `З` | Параллакс мышью |
| `M` / `Ь` | Перелёт к Млечному Пути |
| `?` | Диалог «О Ланиакее» |

В полях ввода и при нажатых `Ctrl`/`Cmd`/`Alt` обработчик клавиш не срабатывает,
чтобы не мешать стандартным сочетаниям браузера.

## Состояние в URL

Позиция камеры и настройки сохраняются в параметрах строки запроса, поэтому ссылку
можно скопировать и передать — приложение восстановит тот же ракурс.

| Параметр | Значение |
|---|---|
| `cx`, `cy`, `cz` | Позиция камеры |
| `tx`, `ty`, `tz` | Цель камеры (точка вращения) |
| `ti` | Индекс точки тура |
| `real` | Режим реальных галактик (`1`/`0`) |
| `bloom` | Свечение (`1`/`0`) |
| `parallax` | Параллакс (`1`/`0`) |

## API

| Метод | Путь | Ответ |
|---|---|---|
| `GET` | `/api/galaxies` | Компактный датасет галактик. Статический, `revalidate = 86400`, кэш `max-age=86400` |
| `POST` | `/api/tts` | Тело `{ "text": "…" }` → `audio/mpeg`. Без ключей отвечает `503` с подсказкой, и клиент переходит на Web Speech API |

## Данные и источники

- **Tully, R. B. et al. (2014).** «The Laniakea supercluster of galaxies», *Nature* 513, 71–73 —
  границы сверхскопления и Великий аттрактор.
- **Cosmicflows** — каталог расстояний и собственных скоростей галактик, положенный в
  основу распределения точек.

Фоновые галактики генерируются детерминированно по статистике каталога, поэтому
серверная и клиентская копии датасета идентичны. Это **репрезентативная модель**,
а не точная копия неба: реальные публикационные координаты имеют только 20 именованных
объектов.

Масштаб сцены: **1 Мпк = 0.55 условных единиц**.

## Деплой

`next.config.ts` включает `output: "standalone"`, поэтому `bun build` готовит
самодостаточную сборку в `.next/standalone`. `Caddyfile` описывает обратный прокси
`:81 → localhost:3000` и отдельный обработчик запросов с параметром `XTransformPort`.
